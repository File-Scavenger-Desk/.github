# File Scavenger — named scan for deleted files you own

File Scavenger holds a recovery desk for deleted files on a volume you own or are authorized to scan: the named volume scan, the hit list, and a short note the next operator can read. Extra disks wait for their own title.

## Session Card

| Slice | What you do in File Scavenger | What remains |
|-------|------------------------|--------------|
| Arrival | Open File Scavenger and name today's recovery desk | A titled volume scan |
| Focus | Keep only live hits on the File Scavenger board | A short deleted-file list |
| Check | Read File Scavenger deleted files before a large restore | A confirmed recovery desk |

## How File Scavenger Sits

File Scavenger does not replace an empty-folder guess, a scan of volumes you do not own, or a pass on media that is not yours. It sits beside them as a named recovery desk for one job: which deleted files are live, which volume scan still matches a disk you own, and what the next operator should read.

## Traffic Light

| Signal | On the File Scavenger board | What you do |
|--------|----------------------|-------------|
| Green | Named volume scan, short live hit list | Continue the same deleted files |
| Amber | Two disks mixed on one scan | Split the hits before a large change |
| Red | No title, no note, an empty-folder guess | Stop and name the recovery desk first |
| Clear | Handoff written, live scans few | Close File Scavenger and leave the recovery desk |

## Open Order

1. Open the last File Scavenger recovery desk, not a new empty volume scan.
2. Confirm the disk is one you own or are authorized to recover, then read the last handoff.
3. Finish one visible named scan inside File Scavenger on that owned volume.
4. Write what changed, then close with fewer empty-folder guesses than you found.

## Desk Fit

| Who | What File Scavenger holds |
|-----|--------------------|
| Recovery desk | Deleted files, volume scan, and the own disk you keep |
| Shared PC | One File Scavenger profile per operator |
| Lab pass | A named volume scan on media you are allowed to scan |
| Home | Personal volumes you own, out of anyone else's disks |

## After a Week

A week in File Scavenger is not a larger pile of empty-folder guesses. It is the same title, a shorter live hit list, and a note that still makes sense before the next named volume scan. Take finished hits off the live set so the next visit starts on the recovery desk that is still open.

## Sign-off

- [ ] The File Scavenger workspace name is short enough to scan
- [ ] Only volumes you own or may recover sit on the board
- [ ] A second operator can read the hit-list handoff
- [ ] The last File Scavenger volume scan still opens after a restart

## Field Note

File Scavenger is easier to trust when the recovery desk stays on a volume you own. Name the scan, keep the live deleted files, finish one visible pass, and write what changed. Do not scan disks you are not authorized to recover.
